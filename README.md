# Personal Portfolio Web Application

## About

This project is a responsive personal portfolio web application
developed as part of the Full Stack Development Assignment-1.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript ES6+

## Features

- Responsive design
- Semantic HTML5 structure
- Bootstrap navbar and grid
- Project cards
- Project filtering
- Dark/Light theme switching
- Contact form validation
- Dynamic JavaScript content
- Accessibility-friendly form labels
- Mobile responsive layout

## Sections

- Home
- About Me
- Education
- Skills
- Projects
- Achievements
- Contact

## How to Run

Open `index.html` in a web browser.
